# Contract

Edit the file in place. Meaning unchanged. Everyday words; no harder
shortening. Do not explain (`expand`).

## Scope (prompt first)

1. Pointed span (selection / quote / sentence / word) → that only. Default.
2. Prompt names larger scope → honour it (paragraph / section / whole file /
   bullets only / leave formulas).
3. How much: 縮一點 → light; half / 大幅 → purpose-critical only; ~N lines/words
   → aim near N.
4. Scope or how-much unclear → ask once and stop.

## How

1. Purpose of this part (contrast / step / limit / claim).
2. Keep what serves purpose under how-much; drop filler and repeats.
3. Leave untargeted structure (headings, formulas, figures, `<!-- notes -->`).

## Reply

One short note: scope, how much, what you cut.
